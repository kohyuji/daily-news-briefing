# 고정 편집·저장·발행 규칙

HQ 추가 지시(2026-11-12): Brave 등 개인 브라우저를 제어하지 않는다. 인증이나 권한이 부족하면 필요한 부분을 설명하고 브라우저 제어로 자동 전환하지 않는다.

이 파일은 HQ 요청의 운영 규약이다. 매주 금요일 11:00 Asia/Seoul, 독립 Work/Codex 예약 작업에서 실행한다. 실제 예약 설정은 GPT-6.1 Sol (`gpt-6.1-sol`), Medium, Standard를 목표로 하며 프롬프트에 적는 것으로 설정을 갈음하지 않는다. Actions는 저장한 콘텐츠의 정적 빌드·배포만 맡는다. AI API나 별도 유료 서비스는 도입하지 않는다.

## 독자와 문체

세계정세와 세상사를 기초부터 배우는 성인 독자에게 전문 논술 교사가 장기적으로 가르친다. 차분한 존댓말, 용어 첫 등장에 짧은 풀이. 사전 지식은 가정하지 않되 유아적으로 쓰지 않는다. 배경·인과관계·쟁점·서로 다른 관점을 설명하고 제목 나열·단편 요약으로 끝내지 않는다.

## 선정과 기간

한 회차는 Markdown 한 문서에 정확히 15개 기사다. 순서는 세계정세·외교·국제정치(`world`), 한국 정치·경제·사회(`korea`), 문화예술·콘텐츠 산업(`culture`), 과학기술(`technology`), 자연과학·기초과학(`science`)이며 각 3개다.

문화는 만화·애니메이션·영화·출판을 우선하며 게임·인터랙티브 콘텐츠와 예술계도 포함한다. 과학기술은 AI·디지털·우주개발·산업기술·기술정책 등, 자연과학은 생물·생태·동식물·환경·지구과학·물리·화학·천문학 등이다.

직전 **성공** 회차 조사 기준 시각 이후부터 이번 조사 기준 시각까지의 새 소식을 우선한다. 첫 회차는 최근 4일이다. 중요한 보도가 부족한 분야만 7일 이내로 보충하며 기사에 **7일 이내 보충** 표시를 한다. 기존 발표를 최근 재전재한 것은 새 발표로 취급하지 않는다. 원문의 사건·발표일과 기사 게시일을 분리하고 모르는 날짜는 `미확인`으로 쓴다. 회차 머리에 실제 대상 기간·조사 기준 시각을 KST로 명시한다.

사회적 중요도·장기 영향·학습 가치·신뢰성을 우선한다. 단순 화제·연예 홍보·제품 홍보 제외. 동일 사건을 분야 사이에도 중복 선정하지 않는다. 다시 다루는 사건에는 의미 있는 새 변화가 필요하다. 최근 요약에서 확인하고 이전 설명은 1~2문장만 복습하며 가능한 경우 이전 기사 앵커를 연결한다.

## 기사별 깊이

15개 모두 비슷한 깊이로 다음 내용을 자연스럽게 이어 쓴다. 해당하지 않는 항목은 억지로 채우지 않는다.

1. `[새 이슈]`, `[계속되는 이슈]`, `[상황 변화]` 중 하나, 제목, 사건 발생일 또는 발표일, 기사 게시일.
2. 확보한 경우 제목 바로 아래 실제 관련 이미지 최대 1장과 캡션. 없으면 `관련 이미지 미확보`.
3. 무슨 일이 있었고 무엇이 새로 달라졌는지.
4. 이해에 필요한 국가·기관·인물·제도·역사·이전 사건의 배경.
5. 원인·이해관계: 누가 무엇을 원하며 왜 충돌하는지.
6. 중요성과 한국 또는 일상에 가능한 영향. 조건부 영향을 단정하지 않는다.
7. 실제 중요한 쟁점·입장 차이. 억지 양비론 금지.
8. 앞으로 확인할 점.
9. 실제 읽은 핵심 출처·보조 출처의 기관, 제목, 게시일, 일반 웹 원문 링크.

과학 기사에서는 연구 질문, 방법·근거, 결론, 한계, 미확정 부분을 분리한다. 동료심사·연구 단계가 중요하면 명시한다. 상관관계를 인과로, 예비 결과를 확정으로 바꾸지 않는다. 정치식 찬반 구도를 만들지 않는다. 문화 기사는 산업구조·창작노동·자본·유통·저작권·기술 변화·표현의 의미 가운데 관련 맥락을 설명한다.

각 분야 끝에 사실·해석·가치판단을 구분한 짧은 **논술 선생님 정리**를 붙인다. 의미 있는 덧붙임이 없으면 생략한다.

## 원문 검증

기사마다 기본 핵심 1개와 신뢰도 높은 보조 1개를 실제로 읽는다. 공식 발표·법령·통계·논문을 우선하되 이해당사자 주장과 확정 사실을 구분한다. 가능한 독립 취재나 연구로 교차 확인한다. 같은 보도자료·통신기사 전재는 독립 검증으로 계산하지 않는다. 독립 검증이 없으면 한계를 명시하고 내용을 좁힌다.

인명·기관·수치·핵심 날짜·중요 주장을 원문에서 확인한다. 검색 결과 요약만 읽고 쓰지 않는다. 충돌·중요 불확실성은 추가 검증하며 남은 미확인은 그대로 표시한다. 직접 설명하고 원문을 길게 복제하지 않는다. 채팅 전용 인용 표식을 홈페이지에 복사하지 않는다. 출처 메모는 `.ops/research/`에 짧게 기록하고 새 변화·충돌·오류가 없으면 검증한 메모를 재사용한다.

## 이미지: 한 차례 확인, 재탐색 금지

기사 조사와 함께 직접 관련 실제 이미지를 한 차례 확인한다. 보도사진·공식 행사사진·작품 스틸·연구 공식 사진/도표 우선. 일반 자료사진·AI 생성·다른 사건 사진 금지. 공식 공개 자체는 재업로드 허가가 아니다. 공개 재게시 조건 또는 허락을 확인한 파일만 `assets/images/YYYY/MM/YYYY-MM-DD/`에 저장하고 본문에서 표시한다.

캡션에는 기관·촬영일 또는 공개일(모르면 미확인)·원출처 링크·필요한 이용조건을 쓴다. 못 찾거나 권리가 불확실하면 **추가 이미지 검색·재탐색·기사 교체 없이** 미확보 표시 후 발행한다. 회차 0~15장 모두 정상이다. 확보한 이미지만 공개 화면에서 검사하고 안 보이면 제거하고 미확보로 바꾼다. 이미지 때문에 발행을 늦추지 않는다.

## 누적·고정 구조·연속성

원본은 `_posts/YYYY-MM-DD-briefing.md`. 홈페이지는 같은 본문을 빌드하여 표시하며 방문 시 AI를 호출하지 않는다. 기존 회차를 보존하고 같은 날짜 재실행은 같은 파일을 수정한다. 발행일 기준 연도→월→회차 목록과 최신·최근 회차는 빌드 시 자동 생성한다. 대상 뉴스 기간은 별도 표시한다. 한국시간·프로젝트 baseurl을 모든 날짜·링크·이미지에 적용한다.

초기 구축 후에는 템플릿·스타일·빌드 설정을 기능 변경 또는 오류 수정 때만 바꾼다. 새 회차 Markdown·확보한 이미지·목록용 메타데이터·연속성 요약만 추가/갱신한다. `.ops/`, `docs/`, `AGENTS.md`, 템플릿·스크립트는 배포하지 않는다. 공개 저장소에 있으므로 운영 파일에 비밀정보는 쓰지 않는다.

최근 이슈 요약은 최대 30개·약 2,000토큰 목표다. 이슈 ID·제목·핵심 변화·회차 기사 링크와 직전 성공 조사 기준을 기록한다. 매회 전체 저장소·과거 본문을 읽거나 여러 모델로 중복 조사하거나 전체 본문을 다시 작성하지 않는다.

## 완료와 알림

5×3=15, 중복 사건, 날짜, 주요 주장, 원문 출처, 링크를 편집 검토하고 빌드 검증한다. 저장소 반영과 공개 배포를 구분하여 회차·홈·연도·월 목록·확보 이미지까지 확인한다. **공개 발행 성공 후에만** 성공 조사 기준 시각을 갱신한다. 실패하면 이전 성공 기준을 보존한다.

본문은 홈페이지에만 저장하며 채팅·알림에 다시 붙이지 않는다. 정상 발행 알림은 해당 회차 홈페이지 링크 **한 줄만** 보낸다. 실패 시 실패 사실과 이유를 짧게 알리며 발행 완료라고 보고하지 않는다.
